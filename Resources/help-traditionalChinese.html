AgentAura 說明

這一頁完全離線可讀，不需要網路，也不用懂程式。

快速上手

  1. 打開 AgentAura，面板會顯示「還沒接上」，按一下藍色的「接上」。
  2. 開一個新的 Claude Code 對話（已經開著的視窗不會自動生效，見下面「什麼時候生效」）。
  3. 之後 Claude Code 在跑、在等你、出錯或跑完的時候，選單列的燈就會自動變色。

面板底部「Options ⌄」裡還有幾個常用設定，見下面「Options 選單在做什麼」。

燈號是什麼意思

選單列上會亮起顏色，代表你所有 Claude Code 視窗裡「最需要你注意」的那一個狀態：

  • 紅色（錯誤）—— 有個 session 出錯了，需要你看一眼。
  • 橘色（等你）—— 有個 session 在等你回應（例如允許某個操作）。
  • 藍色（執行中）—— 有 session 正在跑，不需要你做什麼。
  • 綠色（已完成）—— 有 session 剛跑完，等你去看結果。

沒有任何 session 在跑時，選單列會維持全暗，幾乎看不出來——這是刻意的，安靜比顯眼更重要。

四種燈號同時存在時，顯示順序固定是「錯誤 > 等你 > 執行中 > 已完成」——只要有一個 session 出錯， 整顆圖示就會亮紅色，不會被其他 session 蓋掉。

為什麼有八顆燈

選單列圖示畫了八顆小燈，但這個數字跟你有幾個 session 在跑沒有關係—— 不是「8 個 session」的意思，八顆燈永遠一起亮同一個顏色，純粹是視覺設計，讓顏色在小小的選單列上更容易被餘光注意到。

要看實際有幾個 session、各自在做什麼，點一下圖示打開面板，裡面會列出每一個 session 的詳細狀態。

怎麼改顏色

點選單列圖示打開面板，底部會有一排小色點，那就是四種狀態目前用的顏色。

  1. 點想改的那個色點，會跳出 macOS 內建的選色器。
  2. 拖動選色時，選單列的燈（如果現在正好是那個狀態）跟面板上的色點會即時跟著變。
  3. 選色器開著的時候面板不會自動關掉，可以慢慢挑。
  4. 想恢復預設值，按 Options 裡的「重設顏色」即可一次全部還原。

「idle（沒事發生）」那個極暗的灰色不能改——它必須維持幾乎看不見，才不會跟其他狀態搶注意力。

hook 是什麼、為什麼要「接上」

AgentAura 本身看不到 Claude Code 在做什麼——它得靠 Claude Code 在每個關鍵時刻 （開始跑、開始等你、出錯、跑完……）主動通知一下，這個通知機制在 Claude Code 裡叫「hook」。

「接上」指的就是告訴 Claude Code：往後每次發生這些事，也順便通知 AgentAura 一聲， 讓它更新選單列的燈號。這一步只會建立一個指向這個 App 的掛載，不會更動 Claude Code 既有的任何設定， 隨時可以一鍵移除、完全復原。

什麼時候生效

按下「接上」之後，要從下一個新開的 Claude Code session 起才會生效—— 這是 Claude Code 載入外掛的方式決定的，不是 AgentAura 刻意設計的延遲。

現在已經開著的視窗不受影響，不需要重新啟動、也不需要重開 AgentAura 這個 App 本身， 只要開始一個新對話（或關掉終端機再重開一個），新的 session 就會自動接上。

怎麼移除

面板的「Options」裡有一鍵移除掛載，按下去就會把「接上」那一步建立的掛載刪掉， Claude Code 不會再通知 AgentAura 任何事，畫面會回到「還沒接上」的樣子。

移除掛載不會刪掉這個 App，也不會留下任何殘留設定——AgentAura 從頭到尾都沒有寫過 Claude Code 的設定檔，所以移除永遠是乾淨的。

怎麼完整移除 AgentAura

如果連這個 App 本身都不想留，Options 裡的「完整移除 AgentAura」會依序：取消「開機自動 啟動」、移除掛載（同上）、刪除 ~/.agentaura 底下所有 session 紀錄、清掉顏色與 開關等偏好設定，最後把 AgentAura.app 移到垃圾桶並結束這個 App。

App 進垃圾桶前都可以還原；按下去之前會先跳出對話框，列出上面這幾件事， 不會沒說清楚就動手。

搭配 Codex 使用

AgentAura 也認得 OpenAI 的 Codex CLI，用同一套方式運作——一顆燈、一份面板，兩邊共用。 如果你的機器上有 ~/.codex，裝了 Codex 之後這裡會多出第二張卡片。

  • 接上 Codex—— 寫入 ~/.codex/hooks.json，讓 Codex 也通知 AgentAura。絕不碰 ~/.codex/config.toml，而且只在那個檔案還不存在時才寫。
  • 下次開啟 Codex 時，它會問你一次是否信任這個 hook，要按同意燈才會動——AgentAura 沒辦法知道你按了同意還是拒絕，只能先講清楚會有這個提示。
  • 重新接上 Codex—— 如果 App 在接上之後被搬走，這裡會換成這一列， 按下去用 App 現在的位置重建同一份掛載。
  • 移除 Codex 掛載…—— 只刪掉 AgentAura 自己寫的那份 hooks.json 項目。如果你本來就有自己的 ~/.codex/hooks.json，AgentAura 不會動它，只會顯示一段可以手動貼上的設定。 把這些 entry 併進你現有的 hooks 物件，不要整份取代。

Codex 的 session 沒有專門的「錯誤」訊號可以回報給 AgentAura——只跑 Codex 的時候， 那顆紅燈永遠不會亮，只有 Claude Code 的 session 才會。

Options 選單在做什麼

點面板底部的「Options ⌄」（或直接在選單列圖示上按右鍵）會展開這些項目：

  • 說明與快速上手—— 就是這一頁。
  • 開機自動啟動—— 開機時自動打開 AgentAura，不用每次手動開。
  • 減少動態—— 關掉選單列圖示的呼吸／閃爍動畫，只保留顏色本身。 如果是你自己打開這個選項（不是系統的「減少動態效果」幫你關的），要知道「等你」跟 「出錯」在圖示上會變成只靠顏色分辨，看得比較快一點，不要只靠眼角餘光掃過去。
  • 燈條底板—— 預設開啟：燈的底下墊一塊不透明深色底板，讓對比在任何桌布、 深色或淺色選單列下都一樣。關掉之後燈直接疊在選單列上，在某些桌布顏色下可能比較難看清楚。
  • 選單列 icon 造型—— 點下去會跳出一個小選單，可以選內建的幾種造型 （預設的 LED 燈條、圓點、圓環、藥丸、星芒、半圓）。顏色跟動畫完全不變，只有形狀不同。
  • 重設顏色—— 見上面「怎麼改顏色」。
  • 顯示語言—— 切換面板文字用英文還是繁體中文，預設英文。
  • 重新接上 Claude Code—— 掛載壞掉或被搬走之後，用這個重建， 跟第一次「接上」是同一件事。
  • 再檢查一次—— 只有「已接上但還沒驗證」這個狀態才會出現， 按下去重新確認 hook 真的能跑。
  • 移除掛載—— 見上面「怎麼移除」。
  • 完整移除 AgentAura—— 見上面「怎麼完整移除 AgentAura」。
  • 關於 AgentAura—— 版本號、專案網址、授權狀態。
  • 回報問題—— 開瀏覽器到 GitHub 回報 bug 或提建議。
  • 離開 AgentAura（快捷鍵 ⌘Q）—— 結束這個 App；面板打開的時候也可以 直接按 ⌘Q。

常見問題

按了「接上」，但燈還是不會亮

先確認你是不是還停留在按「接上」之前就開著的那個視窗——照上面「什麼時候生效」那條， 舊視窗不會自動生效，開一個新的對話或新終端機看看。

如果新開的也不亮，很可能是下一條：macOS 擋住了 hook。

macOS 擋住了 hook，要去哪裡允許

App 如果是從網路下載的，macOS 會先把裡面的執行檔隔離起來，導致 hook 每次都被系統擋下。 通常會看到面板顯示「macOS 擋住了 hook」。可以這樣處理：

  • 先確認 App 已經在「應用程式」資料夾裡（見下一條），重新打開一次；
  • 或到「系統設定 → 隱私權與安全性」，找找看有沒有跟這個 App 有關的允許選項。
App 在「下載項目」或專案的 build/ 資料夾下

請先把 App 拖進「應用程式」資料夾再打開。放在「下載項目」或開發用的 build/ 資料夾裡的 App，位置隨時可能改變或被系統當成暫時檔案處理，接上之後很容易又莫名其妙壞掉。

搬進「應用程式」是一次性的，搬好之後正常使用不會再遇到這個問題。

App 被搬走了 / 改了名字

接上的掛載是指向當時那個 App 檔案的，如果之後把 App 移動、改名或刪除， 燈就會停在暗的，面板會顯示「重新接上」。把 App 放回原本的位置， 或是移到新位置後在面板按一次「重新接上」即可。

燈亮了又暗了，是不是壞了

不是壞掉——只有「需要你注意」的狀態（等你、出錯）才會用有動畫的方式提醒你， 「執行中」跟「已完成」則刻意安靜，不吸引視覺注意力。這是設計上的取捨： 真正需要處理的事才值得打斷你。

這份說明隨 App 一起收在裡面，離線就能開。
