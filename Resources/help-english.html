AgentAura Help

This page works entirely offline — no internet connection needed, and no coding knowledge required.

Quick start

  1. Open AgentAura — the panel will show “Not connected.” Click the blue “Connect” button.
  2. Start a new Claude Code conversation (a window that's already open won't pick this up automatically — see “When does this take effect” below).
  3. From then on, whenever Claude Code is running, waiting on you, hits an error, or finishes, the menu bar light changes color on its own.

The “Options ⌄” section at the bottom of the panel has a few more settings you might use often — see “What's in the Options menu” below.

What the lights mean

A color lights up in the menu bar for whichever status needs your attention most, across all your Claude Code windows:

  • Red (error) — a session hit an error and needs a look.
  • Orange (waiting) — a session is waiting on you to respond (for example, to approve an action).
  • Blue (working) — a session is running; nothing needed from you right now.
  • Green (done) — a session just finished; check the result whenever you get a chance.

When nothing is running, the menu bar stays fully dark — barely visible. That's intentional: quiet matters more than eye-catching.

When more than one status could apply at once, the display order is fixed: “error > waiting > working > done” — if even one session has an error, the whole icon turns red, and no other session's status can override that.

Why eight dots

The menu bar icon draws eight small dots, but that number has nothing to do with how many sessions you have running — it doesn't mean “8 sessions.” All eight dots always light up in the same color together; it's purely a visual design choice that makes the color easier to catch out of the corner of your eye in the small menu bar.

To see how many sessions are actually running and what each one is doing, click the icon to open the panel — it lists every session's detailed status.

How to change the colors

Click the menu bar icon to open the panel; a row of small color dots at the bottom shows the colors currently used for the four statuses.

  1. Click the dot you want to change, and macOS's built-in color picker pops up.
  2. While you're dragging in the picker, the menu bar light (if it's currently showing that status) and the dot in the panel update live.
  3. The panel won't close on its own while the color picker is open, so you can take your time choosing.
  4. To go back to the defaults, use “Reset colors” in Options to restore all four at once.

The very dark gray used for “idle (nothing happening)” can't be changed — it has to stay almost invisible so it doesn't compete for attention with the other statuses.

What's a “hook,” and why “Connect”?

AgentAura can't see what Claude Code is doing on its own — Claude Code has to actively tell it at key moments (starting a run, waiting on you, hitting an error, finishing…). That notification mechanism is called a “hook” in Claude Code.

“Connect” tells Claude Code: from now on, also let AgentAura know whenever these things happen, so it can update the menu bar light. This step only sets up a mount pointing at this app — it does not change any of Claude Code's existing settings, and it can be removed with one click at any time, fully reverting.

When does this take effect?

After you click “Connect,” it only takes effect starting with the next new Claude Code session you open — that's how Claude Code loads plugins, not a delay AgentAura chose on purpose.

Windows that are already open aren't affected — you don't need to restart them, and you don't need to restart AgentAura itself either. Just start a new conversation (or close the terminal and open a new one), and the new session connects automatically.

How to remove the mount

“Options” in the panel has a one-click “Remove mount…” — click it and the mount created by “Connect” is deleted. Claude Code stops notifying AgentAura of anything, and the screen goes back to “Not connected.”

Removing the mount doesn't delete this app or leave behind any settings — AgentAura never writes to Claude Code's configuration files at any point, so removing it is always clean.

How to completely remove AgentAura

If you don't want to keep the app at all, “Completely remove AgentAura…” in Options will, in order: turn off “Launch at login,” remove the mount (as above), delete every session record under ~/.agentaura, clear color and toggle preferences, then move AgentAura.app to the Trash and quit the app.

The app can still be restored from the Trash any time before it's emptied — a dialog listing exactly these steps appears before anything happens, so nothing is done without telling you first.

What's in the Options menu

Clicking “Options ⌄” at the bottom of the panel (or right-clicking the menu bar icon) expands these items:

  • Help & quick start… — this page.
  • Launch at login — opens AgentAura automatically at login, so you don't have to open it by hand every time.
  • Reduce motion — turns off the breathing/blinking animation on the menu bar icon, keeping only the color itself. If you turned this on yourself (rather than the system's own “Reduce Motion” doing it for you), keep in mind that “waiting” and “error” will then only be told apart by color — take an extra look instead of relying on peripheral vision alone.
  • Icon backdrop — on by default: adds an opaque dark backing behind the lights so contrast stays consistent on any wallpaper, in a light or dark menu bar. Turn it off and the lights sit directly on the menu bar, which can be harder to see against some wallpaper colors.
  • Reset colors — see “How to change the colors” above.
  • Language — switches the panel text between English and Traditional Chinese; defaults to English.
  • Reconnect Claude Code — rebuilds the mount if it's broken or was moved; it's the same action as the very first “Connect.”
  • Check again — only shows up in the “connected but not yet verified” state; click it to re-confirm the hook actually works.
  • Remove mount… — see “How to remove the mount” above.
  • Completely remove AgentAura… — see “How to completely remove AgentAura” above.
  • About AgentAura — version number, project URL, license status.
  • Report an issue… — opens a browser to GitHub to report a bug or suggest something.
  • Quit AgentAura (⌘Q) — quits the app; you can also just press ⌘Q while the panel is open.

FAQ

I clicked “Connect” but the light still won't turn on

First check whether you're still in a window that was already open before you clicked “Connect” — per “When does this take effect” above, old windows don't pick this up automatically. Try a new conversation or a new terminal window.

If a brand-new one still won't light up, it's likely the next item: macOS is blocking the hook.

macOS is blocking the hook — where do I allow it

If the app was downloaded from the internet, macOS quarantines the executables inside it, which blocks the hook every time. You'll usually see “macOS blocked the hook” in the panel. Try this:

  • Make sure the app is already in the Applications folder (see the next item), then reopen it;
  • or go to System Settings → Privacy & Security and look for an allow option related to this app.
The app is in Downloads or the project's build/ folder

Drag the app into the Applications folder first, then reopen it. An app sitting in Downloads or a development build/ folder can have its location change, or get treated as a temporary file by the system, at any time — the mount can very easily break again for no obvious reason right after connecting.

Moving it into Applications is a one-time step; after that, normal use won't run into this again.

The app got moved or renamed

The mount created by “Connect” points at that specific app file — if you later move, rename, or delete the app, the light stays dark and the panel shows “Reconnect.” Put the app back where it was, or, after moving it, click “Reconnect” once in the panel.

The light turned on and then off again — is something broken?

Nothing's broken — only the statuses that need your attention (“waiting,” “error”) use an animated cue to catch your eye; “working” and “done” are deliberately quiet and don't try to grab your attention. That's a deliberate trade-off: only things that actually need handling are worth interrupting you for.
