AgentAura 操作層重新規劃

2026-09-10 · brainstorm 階段（尚未寫 spec）· 參考 Amphetamine 5.x、OpenUsage 0.7.10
現在的 AgentAura 是一個只有主功能、沒有外殼的 app。狀態顯示做到了像素級（八顆燈、聚合優先序、動畫曲線都有 gate 守著）， 但缺少每個選單列 app 都有的那一層：離開、設定、關於，以及最關鍵的一句——「我到底有沒有接上？」 非工程師開起來看到八顆暗燈，無法分辨「沒 session 在跑」、「Claude Code 沒開」、「hook 根本沒裝」—— 這三件事目前在畫面上長得一模一樣。這是「太工程師」真正的來源，不是配色也不是字級。

2從它們身上抽出的五條模式

① 一個入口，全部東西

兩個 app 都沒有 Dock icon、沒有主視窗。所有東西——資料、設定、關於、離開——都從點一下選單列圖示長出來。 我們的 LSUIElement 是對的，缺的是那個「長出來」的下半部。

② 無聊但必要的東西集中在底部

OpenUsage 的 footer：左邊OpenUsage 0.7.10 / Next update in 5m，右邊一顆Options ⌄。 Amphetamine 用分隔線把 About / Feedback / Quit 押在最下面。 模式是：把行政事務收成一格、視覺上壓低，不要跟主資料搶。

③ 存活證明是一等公民

「Next update in 5m」不是裝飾——它讓你在數字看起來不對時，知道問題不在 app 死了。 我們更需要：因為我們的資料來自一個使用者看不見的 hook，而它可能根本沒裝。

④ 標準動詞、標準快捷鍵

⌘Q 離開、⌘, 設定、⌘X 主要動作，而且寫在選項旁邊。幾乎零成本，但這是「這是一個真的 app」最便宜的訊號。

⑤ 設定的規模要配得上 app 的規模

Amphetamine 有九個 tab，是因為它真的有九個子系統（觸發器、熱鍵、硬碟保活、統計…）。 我們只有四個設定。照抄一個設定視窗＝抄錯了那一半。

⑥（反例）不要抄的：資料野心

OpenUsage 的 30 天趨勢、成本圓餅、用量進度條，來自它會存歷史、會打 API。 我們的 scope 是「現在如何」，且刻意不存任何歷史。抄了就要資料庫、保留政策、隱私說明——那是另一個產品。

3底層不動（已定案，本輪不碰）

八顆 LED ＋ 不透明底板（A2，證據決定）IconState 聚合與 D1 優先序 主／副槽分離waiting 不進尾巴（§2.4.1）idle_prompt 不映射 waiting 關面板才 acknowledge（§3.7）hook 契約與 141 個實測 payload aura-hook 一律 exit 0、輸出全空絕不寫 settings.json（D3/R6）四色可改、idle 不可改

本輪只做「使用者的手指碰得到」的那一層。任何提案若需要改上面任一條，就不做。

4要做（七項）

#項目為什麼非做不可成本
M-1離開 AgentAura（⌘Q）現在唯一的關閉方式是 pkill。這是「太工程師」最大的單一破口——一個裝好後關不掉的選單列常駐程式，對一般使用者是恐怖的。極低
M-2「接不上」狀態面板 ＋ 一鍵接上spec §3.8 寫了自我健檢、DoD 寫「死 hook 偵測 100%」，但實際從來沒實作（M5 漏掉，沒人抓到）。沒接上時面板長得跟「沒 session」一樣。${CLAUDE_PLUGIN_ROOT} 是相對路徑，所以把 plugin/ 放進 app bundle、由 app 自己建 symlink，技術上完全可行且零 hook 改動。中
M-3開機自動啟動觀測工具重開機就消失＝壞的。目前只能手動拖進「系統設定 → 登入項目」。SMAppService.mainApp（macOS 13+）一個開關。低
M-4關於／版本使用者要能回答「我裝的是哪一版」。OpenUsage 直接印在 footer。極低
M-5設定入口（Options ⌄）承載 M-1／M-3／M-4 ＋ 重設顏色 ＋ 移除掛載 ＋ 說明。一個選單，不是一個視窗。低
M-6移除掛載（一鍵）R6 是「一步安裝、一步移除」。有了一鍵接上就必須有一鍵移除，否則只做了一半。低
M-7去工程師化文案claude-fable-5-1 · xhigh · auto → 「Fable 5.1 · 高強度」；「燈固定 8 顆，與 session 數無關」講的是實作細節；空狀態要能分辨三種原因。極低

5不做（以及為什麼）

項目判定理由
獨立的設定視窗（Amphetamine 九 tab）不做我們只有四個設定。視窗＝新的 window controller、狀態雙向同步、LSUIElement 的 activate 例外處理。全部塞進 popover。
統計／歷史／趨勢圖（OpenUsage）不做刻意不存歷史。加了就要資料庫、保留政策、隱私說明。
token／成本顯示不做hook payload 裡沒有成本資料，要另接 API。那是 OpenUsage 的產品，不是我們的。
熱鍵不做我們沒有可觸發的動作（唯讀）。
Dock icon／主視窗不做LSUIElement 是對的。
自動更新（Sparkle）不做開源自建；M6 的 README 足夠。
右鍵直接開 Options加分項約五行，工程師的快速路徑。但不能當唯一入口——非工程師不會右鍵。做完 M-5 再順手加。
系統通知（session 完成／出錯時 banner）下一輪真正的候選，但它改變產品性質：從「餘光看得到」變成「主動打擾」，直接撞 R4 注意力預算。需要自己的 brainstorm（要不要分狀態、要不要免打擾時段、會不會變成第二個 Slack）。

7流程

8要你決定的（兩大三小）

問題一 · 行政區放哪裡

兩種都能塞進 M-1／M-3～M-6，差在版面成本與可發現性。
A
底部 utility bar（OpenUsage 式）— 我的建議 「● 已接上 · v0.1.0」＋「Options ⌄」。多一列（約 28px）。有文字的按鈕，非工程師找得到；健康狀態有位置寫完整句子（「接不上，點這裡修」），不只是一顆點。兩個參考 app 都沒有用裸齒輪。
B
標題列右上一顆齒輪 ⚙︎ 零新增列，健康狀態縮成一顆彩點放在原本「重設」的位置。省 28px，但齒輪對非工程師的可發現性明顯較差，且健康狀態只剩顏色、沒有句子。

問題二 · Options 用系統選單還是面板內展開

面板是 NSPopover；彈出 NSMenu 會搶走焦點，popover 預設會關掉。
A
面板內展開一區（accordion）— 我的建議 無焦點問題、開關是真的 SwiftUI Toggle、一個心智模型（東西都在面板裡）。代價：展開時面板變高；快捷鍵字樣只能當灰字提示。
B
真的 NSMenu 最符合 macOS 慣例、⌘Q 字樣天然。代價：要在選單開啟期間把 popover 釘住——這正是改色時對 NSColorPanel 做的事（.semitransient ＋ menuDidClose 解除），機制現成但又多一條會壞的接縫。

三個小的

1
「接不上」時選單列圖示要不要有變化？ 建議不變（八顆全暗）＋ tooltip 寫「還沒接上」＋ 首次啟動自動開面板一次。理由：拿黃燈當警示會跟「等你」撞色，破壞剛做好的四燈語意（R7）。
2
M-7 文案要走多遠？ 保守＝只改 xhigh／auto 這類代碼字；徹底＝連 headline 的等寬字型與「本輪」等說法一起改。建議保守，因為等寬字在顯示指令與檔名時真的更好讀。
3
一鍵接上要不要一併把 app 搬進 /Applications？ 建議不要——app 自己搬自己很容易出錯（正在執行、權限、Gatekeeper），而且違反「使用者完全掌控」。改成：偵測到 app 在 ~/Downloads 或 repo 的 build/ 底下時，在說明頁提醒一句。

9影響範圍與 R9 帳

會動到的檔案

  • 新增 InstallState.swift（AuraCore：純邏輯，判定 已接上／連結斷／二進位不可執行）
  • 新增 Installer.swift（AuraHookFile：建／刪 symlink，唯一會寫 ~/.claude/ 的地方，且只碰 skills/agentaura）
  • 新增 OptionsView.swift／NotConnectedView.swift、LoginItem.swift
  • 改 PanelView（footer ＋ 三態）、PanelModel（多帶 install 狀態）、AppDelegate（接線）
  • 改 build-app.sh：把 plugin/ 複製進 Contents/Resources/plugin/（app 自我包含）
  • 改 INSTALL.md／README：主路徑變成「開起來、按接上」，終端機那條降級為「開發者路徑」

R9（極輕量）的帳

  • CPU：0——全部是點擊才跑的路徑，不進動畫迴圈。
  • RSS：≈0——沒有新的常駐物件；NSMenu／accordion 都是隨用隨建。
  • 執行檔：+ 幾十 KB。但 bundle 會 + 一顆 universal aura-hook（現有 plugin/bin 的大小），這是自我包含的代價，我認為值得。
  • 啟動時間：健檢是兩次 lstat／access，可忽略（不要學 NSColorPanel.shared 那次 +120ms 的教訓）。
  • 新的 invariant：「只准碰 ~/.claude/skills/agentaura 這一個路徑，其餘 ~/.claude/ 唯讀」——要有 gate 從磁碟／原始碼推導，不是寫在註解裡。

建議把這七項打包成 Change 3「操作層」，走完整 SDD（spec → 四視角審 → TDD → integrator → Tier 1 persona，因為全部踩在 Sources/AgentAuraApp/**）。 它同時把 M5 漏掉的 §3.8 自我健檢補回來，並讓 M6（開源）真的有意義——現在的 README 需要使用者會用終端機。
